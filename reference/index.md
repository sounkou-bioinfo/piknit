# Package index

## Embed the agent in R

Drive a live Pi coding agent from R — one turn, a streaming turn, or a
session.

- [`pi_run()`](https://sounkou-bioinfo.github.io/piknit/reference/pi_run.md)
  : Run one turn of a live Pi agent
- [`pi_stream()`](https://sounkou-bioinfo.github.io/piknit/reference/pi_stream.md)
  : Stream a live Pi agent turn as it happens
- [`pi_session()`](https://sounkou-bioinfo.github.io/piknit/reference/pi_session.md)
  : Open a persistent Pi agent session
